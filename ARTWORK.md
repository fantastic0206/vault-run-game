# Vault Run — Midnight Heist artwork

Original artwork generated for this project using the built-in image generation tool. These are playable interface assets, not screenshots or UI mockups. The live interface renders all names, rules, codes, buttons, timers, and scores as accessible HTML.

| Asset path                   | Purpose                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `public/art/vault-scene.png` | Vault-room environment on the welcome, lobby, active heist, and victory screens.     |
| `public/art/move-atlas.png`  | Three action illustrations: Loot, Steal, Guard. CSS selects one third for each card. |
| `public/art/crew-atlas.png`  | Eight masked-animal operatives in a 4×2 atlas, selected by the existing avatar ID.   |

Images are bundled with the application. No runtime image-generation calls or image API credentials are required. Code-native icons continue to use Lucide. Interface type uses Barlow Condensed, Outfit, and Space Mono with local system fallbacks.

## Vault environment — final prompt

Use case: stylized-concept. Asset type: wide 16:9 background art for an actual browser heist party game, not a UI mockup. Create a lavish cinematic stylized 3D illustrated bank vault interior at midnight. A monumental circular steel vault door stands partially open on the RIGHT HALF of the image, warm glowing gold bars and coins spill from within, purple-blue ambient light, subtle laser lines and atmospheric dust, worn dark navy steel panels, elegant chunky game art materials, dramatic amber rim lighting. On the left half keep shadowed navy wall and atmospheric negative space because real HTML text will be overlaid. Camera eye level, slightly wide angle, rich detailed crafted indie video game environment, crisp readable shapes, sophisticated playful heist adventure. Palette midnight blue #111526, violet #7771be, warm gold #ffd47a. Avoid photorealism, avoid flat corporate illustration, no people, no words, no lettering, no logos, no UI, no watermark. Landscape 16:9 image.

## Action-card atlas — final prompt

Use case: stylized-concept. Asset type: ONE WIDE 3:1 seamless layout atlas of THREE square game-action illustrations, each equal-width tile, side by side, no gaps. All 3 tiles share the same premium chunky stylized 3D heist video-game art style, glowing edge light, rich tactile detail, square centered compositions. Left square: a dark teal canvas burglar's bag full of bright golden coins, gold bars, and one emerald, teal atmospheric background. Middle square: a black leather-gloved thief's hand dramatically clutching a glowing brilliant-cut ruby gemstone, crimson-orange atmospheric background. Right square: ornate purple steel security shield with bright silver face and golden lock centerpiece, violet atmospheric background. Each object's silhouette fits wholly within its own square tile with generous padding. This is ONLY the art layer of real playable cards, HTML labels will be added separately. No words, no typography, no numbers, no borders, no UI, no panel separators, no watermarks. Wide horizontal 3:1 composition.

## Crew atlas — final prompt

Premium stylized 3D animal bank-robber crew portraits, expressive charming faces, elaborate black domino eye masks and dark heist jackets, each chest-up and centered, head fully inside its cell, uniform head size. Dark midnight blue purple backgrounds, warm amber rim light, beautifully crafted game character selection art. Clearly eight individual portraits, one animal per cell. No weapons, no writing, no letters, no text, no lines between cells, no UI, no watermark. Square overall image, exact 4x2 evenly spaced portrait grid.
